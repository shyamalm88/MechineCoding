# Single Number II (LeetCode #137)

> Single Number II (LeetCode #137)

## Category

🟢 IMPORTANT (Bit Manipulation — Counting Bits Mod 3)
Given an integer array nums where every element appears EXACTLY THREE
TIMES except for one, which appears EXACTLY ONCE, find that single one.

You must implement a solution with O(n) time and O(1) extra space.

Example 1:
Input: nums=[2,2,3,2] → Output: 3

Example 2:
Input: nums=[0,1,0,1,0,1,99] → Output: 99

Constraints:
- 1 <= nums.length <= 3 * 10^4
- -2^31 <= nums[i] <= 2^31 - 1
- Each element appears exactly three times except for one which appears once.
